# [Project Seth] 원격 클로드 코드 자동화 러너 (Remote Runner)

상엽님이 폰(메신저)에서 명령을 던지면, 켜져 있는 노트북이 자동으로 `claude` CLI를 실행하고 결과를 회신하는 백그라운드 파이프라인입니다.

---

## 1. 동작 아키텍처

```
[상엽님의 스마트폰 (메신저)]
         │
         │ (메시지: "@claude 이슈 1번 구현해줘")
         ▼
[메신저 서버 (Slack / Discord)]
         │
         │ (WebSocket 실시간 수신 - 포트포워딩 불필요)
         ▼
[상엽님의 노트북 (백그라운드 러너 실행 중)]
         │
         │ 1. `claude "이슈 1번 구현해줘"` 서브프로세스 실행
         │ 2. 로컬 코드 파일 자동 수정 및 git 커밋
         │ 3. 실행 로그 캡처
         ▼
[메신저 채널로 결과 및 git diff 자동 회신]
```

---

## 2. 러너 선택 (Slack vs Discord)

### 옵션 A: Slack 러너 (`slack_runner.py`) - 가장 추천!
- **장점**: 피클(메지)도 슬랙에 연동되어 있어, 상엽님이 피클한테 "클로드한테 작업 시켜"라고 하면 피클이 슬랙에 명령을 대신 쏴줄 수도 있음.
- **방식**: 슬랙 Socket Mode (외부 공인 IP나 ngrok 없이 웹소켓으로 동작).

### 옵션 B: Discord 러너 (`discord_runner.py`)
- **장점**: 디스코드 봇 토큰 하나만 발급받으면 1분 만에 세팅 완료. 모바일 앱 알림이 빠름.
