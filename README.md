# Project Seth (戰神賽特 Next-Gen)

대만 시장 1위 슬롯 문법을 혁신하는 6x5 클러스터 텀블 비디오 슬롯 프로젝트입니다.

## 📌 주요 특징 (Key Features)
- **그리드**: 6 Reels x 5 Rows, Cluster Pays (8+ 매칭)
- **배수 성장 엔진**: 텀블 연쇄 발생 시 배수 심볼 실시간 스텝업 (Grow-on-Tumble)
- **듀얼 캐릭터 시스템**:
  - **Character A (세트)**: 윈 종료 후 배수 심볼 복제 피니시
  - **Character B (네프티스)**: 슈퍼 프리스핀 전용 각성 캐릭터, 심볼 분열 & 듀얼 배수 패널 적립
- **슈퍼 스캐터**: 단 1개의 슈퍼 스캐터로도 슈퍼 프리스핀 직행

## 📁 디렉토리 구조 (Directory Structure)
- `docs/mechanics_spec.md`: 슬롯 코어 메커니즘 및 룰 정의서
- `docs/art_bible.md`: 흑요석/황금/크림슨 통합 아트 스타일 가이드
- `orchestration/agent_roles.md`: Claude Code(두뇌) & Codex(손) 분업 지침서
